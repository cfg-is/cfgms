CFGMStenant admin — cascade lifecycle & access boundary
—

Tenant admin (Issue #3131) — built against ADR-025 (SaaS-operator ↔ MSP access boundary) and ADR-027 (cascade suspend/restore + Suspend→Hold→Delete pipeline). Use the Session switcher inside the frame: MSP admin shows the full cascade-suspend and delete-pipeline demo inside one MSP's own subtree; Root — no grant shows the ADR-025 boundary/empty state; Root — break-glass active shows the same subtree unlocked under a time-boxed, audited elevation. In the MSP admin view: Restore on client-2 demonstrates that an independently-suspended descendant survives an ancestor restore; Request delete on client-3 demonstrates the "not fully suspended" rejection; client-4 shows the hold countdown; client-5 shows the dual-control approve step (toggle "I requested this" to see it lock). Both themes.
